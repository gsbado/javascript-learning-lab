# JavaScript Learning Lab ⚡

A collection of JavaScript exercises created during Web Development classes to practice and strengthen core programming concepts.
This repository includes basic programming exercises, object manipulation, functions, arrays, conditionals, loops, and a simple Node.js backend.

## 📂 Project Structure

```text
JAVASCRIPT-LEARNING-LAB/
├── backend/          # Simple Node.js API
├── docs/             # Documentation and notes
├── exercicios/       # JavaScript exercises
│   ├── alunos.js
│   ├── cadastroAlunos.js
│   ├── disciplinas.js
│   ├── funcoes.js
│   ├── index.js
│   ├── media.js
│   ├── objetoAluno.js
│   ├── situacao.js
│   └── tabuada.js
├── .gitignore
├── package.json
└── README.md
```

## ⚙️ Requirements

- Node.js 18+ (or a recent LTS version)
- npm (Node Package Manager)

## 🚀 Running the Exercises

Run any exercise file using Node.js:

```bash
node exercicios/media.js
```

or

```bash
node exercicios/tabuada.js
```

## 🚀 Running the Backend API

To start the local API server:

```bash
cd backend
node server.js
```

### Available routes:

- `GET /alunos`
- `GET /produtos`

## 📝 Notes

- This repository is focused on learning JavaScript fundamentals through small exercises.
- Backend and API exercises are separated from basic scripting practice.
- Larger projects are maintained in separate repositories.
